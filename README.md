# 🎬 CinaVault Premium — Multi-Platform Media Server

CinaVault Premium is a state-of-the-art, high-performance media server and desktop application built with a modern React frontend and a robust Rust/SQLite backend, packaged securely via Tauri v2.

## 🚀 Key Features
- **Paged Loading:** Optimized library management ensuring smooth performance with large media collections.
- **Stable Poster Caches:** Reliable caching mechanism for media artwork, improving load times and stability.
- **Safe Duplicate Batching:** Intelligent and safe processing of duplicate media files.

## 🛠 Quick Start Setup
1. **Clone:** `git clone https://github.com/johngraven75/CinaVault-Premium.git`
2. **Install:** `npm install`
3. **Dev:** `npm run tauri dev`
4. **Build:** `npm run tauri build`
